# Assets and licensing

Code license and asset permission are separate.

## Public repository rules

- Include an asset only when its license explicitly permits redistribution.
- Keep attribution beside the asset and in an inventory.
- Do not assume that an old recording, religious recording, public website, or
  downloadable file is public domain.
- Do not publish household-only archives copied from a broadcaster.
- Do not publish API tokens, signed URLs, or files whose source terms prohibit
  redistribution.

## Fonts

The public UI uses system/open-font fallbacks. Thmanyah can be loaded locally by
an individual installation, but its font files are excluded from this project
until redistribution permission is documented. A contributor may add an
open-licensed Arabic font pack through a separate, attributable change.

## Audio packs

The planned audio-pack format will contain a manifest with title, reciter,
prayer type, file path, source URL, license, attribution, and checksum. The app
will ship without restricted recordings. Each user may install media they are
legally allowed to use on their own device.
